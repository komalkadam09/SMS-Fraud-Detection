# SMS Spam Detection using Machine Learning

## Project Description
This project classifies SMS messages as Spam or Ham using Machine Learning.

## Dataset
SMS Spam Collection Dataset

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes

## Steps
1. Load Dataset
2. Preprocess Data
3. Encode Labels
4. Convert Text using TF-IDF
5. Split Dataset
6. Train Model
7. Evaluate Model
8. Predict New Messages

## Result
Accuracy Achieved: 96.23%
